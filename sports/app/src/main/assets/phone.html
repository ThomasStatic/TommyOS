Pair this phone

This page needs the pairing code from your TV.

  1. On the TV, open Lumen → Settings → Sports → Pair a phone.
  2. Point your iPhone's Camera at the code and tap the link.

Can't reach the TV

Make sure the TV is on and this phone is on the same Wi-Fi. If the TV's address changed, pair again from Lumen → Settings → Sports.
